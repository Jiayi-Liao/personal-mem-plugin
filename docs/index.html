02 / INSTALL

Two commands. Then start remembering.

Add the marketplace

Codex discovers the plugin from this GitHub repository.

Install the plugin

Start a new conversation after the install finishes.

Choose your folder

Ask Personal Mem to initialize a location you control.

TERMINAL
$ codex plugin marketplace add \
  Jiayi-Liao/personal-mem-plugin
$ codex plugin add \
  personal-mem@personal-mem-local

› Use $personal-mem to initialize my
  memory at ~/.local/share/personal-mem.

04 / HONEST BOUNDARIES

Local-first, with clear edges.

No serviceNo Personal Mem server, account, API key, telemetry, or subscription.
No lock-inYour memory remains readable as files without the plugin.
No silent archiveIt does not copy every conversation or infer permanent preferences by default.
Host processingText used in a conversation is still processed by Codex under your account settings.
